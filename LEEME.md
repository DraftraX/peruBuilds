# PERU BUILDS — versión adaptada sobre la web de Corwin

Es la versión que se veía en http://localhost:4000: la web original de Corwin (corwin.sk) con la identidad de PERU BUILDS (B animada, colores, textos e imágenes provisionales).

## Verla en local

`
cd C:\\Proyectos\\peru-builds-corwin-adaptado
node server.mjs
`

y abrir http://localhost:4000

## Importante

El código (CSS/JS), el diseño, las tipografías (Circular), el video de portada y varios íconos siguen siendo de Corwin o de quien se los licenció. **Sirve como referencia, no para publicarse.**

La versión propia para publicar es C:\\Proyectos\\LPPeruBuilds\\peru-builds-web.

## Qué se cambió respecto al original

- site/en.html: textos, menú, secciones y enlaces de PERU BUILDS.
- site/templates/build/production/project.min.css y project.min-2.js: colores y cierre de la B.
- site/files/peru/: logo vectorizado, máscara de la B, ilustraciones, peru.css, peru.js.
- SVG de site/files/: colores.
